# NodeTorch

NodeTorch enables real-time, scalable data processing through a high-performance, distributed neural network engine.

With NodeTorch, you get a lightweight tool that stays out of your way.

**What you get**

- NodeTorch enables real-time, scalable data
- processing through a high-performance, distributed
- neural network engine

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/NodeTorch.git`
2. `cd NodeTorch`
3. Install in editable mode: `pip install -e .`

## Configuration

NodeTorch is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
